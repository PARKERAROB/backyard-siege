# Backyard Siege

A tower defense game. Toby the dog defends the porch from squirrels, mockingbirds, possums, raccoons, and moles across twelve maps. Open `index.html` in any browser, or play it at the GitHub Pages link on this repo.

Dog sprite frames are from "Dog Sprites" by Shepardskin on OpenGameArt.org (CC0), recolored to match Toby.
